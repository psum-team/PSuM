# 中文

遇到问题或疑问？

- **Bug / 功能建议 / 设计讨论**：请到仓库 Issue 区提 issue（见 [CONTRIBUTING_cn.md](CONTRIBUTING_cn.md) 的「报告问题」节）。
- **上手与文档**：从 [README_cn.md](README_cn.md) 的快速开始与 [文档索引](docs/index.md) 进入。
- 构建或环境问题：优先阅读 [依赖安装](docs/dependency.md) 与 [环境配置与构建](docs/building.md)，并附上 `env_scan.sh` 的输出。

# English

Have a question or ran into a problem?

- **Bugs / feature requests / design discussions**: open an issue in this repository (see "Reporting issues" in [CONTRIBUTING.md](CONTRIBUTING.md)).
- **Getting started**: start from [README.md](README.md) and the [Documentation Index](docs/index_en.md).
- Build or environment trouble: read [Dependency Installation](docs/dependency_en.md) and [Building](docs/building_en.md) first, and include your `env_scan.sh` output.
